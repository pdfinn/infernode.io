InferNode is a 64-bit Inferno® distribution: a complete operating system in
15–30 MB of RAM, where every resource is a file, every process has its own
private view of the filesystem, and AI agents are contained by that view rather
than by a policy engine.

If you have never run it, start with the quick start. It takes about twenty
minutes and ends with an agent doing work it cannot escape from.
